## Стадии
- idea → outline: структура (заголовки, примеры, аудитория, CTA)
- outline → draft: полный черновик в стиле референсов (файлы-референсы передаются)
- draft → ready: полировка, frontmatter по схеме, короткая версия для TG + тизер

## Правила
- Один вызов = один переход.
- Обновляй `status` во frontmatter.
- Сохраняй факты автора; стиль — по референсам.
- Ничего не публикуй (не ставь `published` без явной команды).
