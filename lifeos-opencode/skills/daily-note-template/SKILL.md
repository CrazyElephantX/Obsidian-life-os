## Структура дейлика
Путь: `1. Проекты/diary/ГГГГ/ММ/ГГГГ-ММ-ДД.md`. Шаблон: `4. Архив/Шаблоны/daily.md`.

Frontmatter:
- `tags: [daily]`
- `energy: normal` — low | normal | high
- `content_block: true` — true | false

Секции в порядке:
1. `# Главные задачи дня` — критичное, блок 09:00–13:00
2. `# Дополнительные задачи` — второстепенное, после обеда
3. `# Забота о себе`
4. `# Контент` — вечерний контент-блок
5. Блок-запрос Tasks — скопировать из шаблона ДОСЛОВНО («> [!todo] Задачи на сегодня»), текст не менять
6. `# Зависшие задачи` — генерируется плагином Tasks, НЕ трогать
7. `# Намерения`
8. `# Happenings`
9. `# Спасибо дня`
10. `# Итоги дня` — заполняется в сценарии «Итоги дня»
11. `Related: [[ГГГГ-ММ Месяц]]`

Месячная заметка: путь `1. Проекты/diary/ГГГГ/ММ/ГГГГ-ММ Месяц.md` (например `2026-09 Сентябрь`), обязательная секция `# Задачи месяца`. Если отсутствует — создать по этому правилу.
